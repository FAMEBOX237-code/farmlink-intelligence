2 Sensor node setup
1
Power on your sensor node
Connect your Arduino sensor node to power (solar panel or USB). Wait for the LED to blink 3 times — this means the node started correctly.
2
Make sure it connects to Wi-Fi
The node will automatically connect to the Wi-Fi network it was programmed with. The LED turns solid green when connected. If it does not connect in 60 seconds, check that your Wi-Fi password is correct in the firmware.
3
Enter your node ID
The node ID is printed on the label on your Arduino board. It looks like NODE-001. Enter it below and click Verify to confirm it is online.
Enter your node ID above, then click Verify
