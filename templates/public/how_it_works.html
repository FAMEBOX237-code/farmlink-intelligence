The pipeline

Four steps. Fully automatic.

  1. 1

    Farmer registers & installs the IoT sensor node

    One-time setup

    Creates a FarmLink account, registers their farm, and connects their Arduino sensor node via the setup wizard. Data collection begins automatically — no further action needed.

    Farmer does once Register · Install node · Done
    System does always Logs soil, temperature, humidity, and light every 30 minutes

    Covered in: Register → Add Farm → Farmer Dashboard

  2. 2

    System computes a quality score every 30 minutes

    IoT verified Sensor-computed Cannot be faked

    The QualityScoreEngine reads each new sensor transmission and recalculates a score from 0–100. This score is attached automatically to every listing the farmer creates. No manual input is possible — quality is measured, not claimed.

    Inputs Soil · Temperature · Humidity · Light · Rain
    Output Quality score 0–100 on every listing
    Live quality score example
    Soil moisture
    Good
    Temperature
    Fair
    Humidity
    Good

    Covered in: Farmer Dashboard → Listing Detail

  3. 3

    After 28 days — a harvest forecast is generated

    28-day trigger

    Once 28 days of data exist, the HarvestForecast engine analyses trends to predict the harvest window and confidence score. The forecast is linked to the farm's listings automatically and a buyer alert dispatch is triggered.

    Trigger 28+ days of sensor data on any registered farm
    Output Harvest window · Confidence % · Buyer alert sent
    🗓 Harvest forecast — Tomatoes · Farm 1 Bafoussam Confidence 91%
    Window opens May 14, 2026
    →
    Window closes May 22, 2026
    Days remaining 14

    Covered in: Forecast Detail page → HarvestForecast class

  4. 4

    Registered buyers receive a pre-order alert

    Automatic dispatch

    The AlertDispatcher queries all BuyerAlert registrations matching crop type and region. Matching buyers receive a notification with the forecast window and a link to the listing — before produce is harvested.

    Who gets alerted Buyers matching: crop + region + quality minimum
    What they receive Notification → Listing link → Contact farmer

    Covered in: My Alerts → Buyer Notifications

Common questions

Frequently asked questions

Do I need to buy the IoT sensor node myself? +

The sensor node is provided as part of the FarmLink farmer onboarding kit and installed by your team. It runs autonomously on solar power once set up.

What if my internet or sensor goes offline? +

The node has a local SD card buffer. It stores readings locally and syncs when connection is restored. Buyers see a "last known" status on your listings.

Can I browse as a buyer without registering? +

Yes — you can browse listings and view details without an account. To register alerts and contact farmers directly, you need a free buyer account.

How is the trust score calculated? +

Transaction completion (40%) + on-time delivery (30%) + buyer ratings (20%) + profile completeness (10%). The trust score updates automatically after every transaction.
